# Chitraleheri 🎨✨

**Chitraleheri** is a fast, simple, and intuitive AI creative studio for short-form videos, image generation, video synthesis, and talking character avatars.

---

## 🌟 Core Features

- 🎬 **Shorts Maker**: Paste any long-form video URL or upload a file. Automatically extracts the highest-retention highlights, centers the speaker in a vertical 9:16 aspect ratio, and adds animated subtitle captions (Hormozi, MrBeast, Minimal).
- 🎨 **Image Creator**: Text-to-image generator with curated aesthetic styles (*Cinematic*, *Realistic*, *Anime*, *3D Render*) and prompt enhancement.
- 🎥 **Video Generator**: Bring prompts to life with cinematic camera motions (*Zoom In*, *Pan Left*, *360° Orbit*, *Steady*).
- 🗣️ **Talking Avatar**: Animate portrait photos with natural voiceover and synchronized lip speech.

## 🚀 Quick Start (Local)

1. Clone the repository:
   ```bash
   git clone https://github.com/shivanshgautamsg/chitralahari.git
   cd chitralahari
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🌐 Deployment (GitHub Pages)

This repository includes an automatic GitHub Actions workflow (`.github/workflows/deploy.yml`).
When deployed, the site is hosted live at:
👉 **[https://shivanshgautamsg.github.io/chitralahari/](https://shivanshgautamsg.github.io/chitralahari/)**

To enable GitHub Pages in your repository settings:
1. Go to **Settings → Pages** in your GitHub repository.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` and your website will be live automatically!
